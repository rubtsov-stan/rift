# Security policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | yes       |

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open the Security tab of
[rubtsov-stan/rift](https://github.com/rubtsov-stan/rift), choose "Report a
vulnerability", or go straight to
<https://github.com/rubtsov-stan/rift/security/advisories/new>.

Do not open a public issue for a vulnerability.

Include:

- the Rift version (`rift --version`) and your platform;
- the command line and a description of the input that triggers the problem.
  A pair generated with `rift-gen` and its seed works well;
- what you expected and what happened: a crash, memory use above `--mem`,
  a wrong diff, an out-of-bounds read.

This is a one-person project. I read every report and reply when I can,
without a fixed timeline.
