Diff huge text files under a hard memory limit.

Rift diffs large text files under a heap limit you set on the command line, --mem. It writes a unified diff that patch applies to the first file to get the second, and a terminal view lets you jump through the differences before the whole diff is done.

What is guaranteed

  • The output is a correct edit script: applied to the first file it gives exactly the second, byte for byte.
  • A line counts as unchanged only after its bytes are compared. Hashes only propose matches.
  • The heap stays at or under --mem. Files are read with pread into fixed buffers, never mmap.
  • A region Rift could not refine within the budget is marked approximate in every output.

What is not

  • The diff is not minimal.
  • A moved block shows in the unified diff as a deletion and an insertion. --summary, --stats and the terminal view list moved blocks, and detection does not find every block.
  • Windows is not supported.
